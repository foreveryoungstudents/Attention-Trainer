# 🧠 Тренажёр внимания

Интерактивный браузерный тренажёр с **21 категорией** упражнений и **4 уровнями сложности**.  
Работает без сборщиков, серверов и зависимостей — просто откройте `index.html`.

## Демо

Выложите папку на GitHub Pages:  
`Settings → Pages → Deploy from branch → main / root`

Или просто скачайте ZIP и откройте `index.html` локально.

---

## Категории

| Раздел | Упражнения |
|--------|-----------|
| **Внимание — базовые** | Тест Струпа, Концентрация, Поиск в сетке, Найди различия, Устный счёт, Сетка по памяти |
| **Таблицы Шульте** | 5×5, 7×7, Хаос (разные шрифты/ориентации/цвета) |
| **Память и последовательности** | Память на слова, Числовые ряды, Паттерны |
| **Межполушарное взаимодействие** | Руки и знаки, Соотнеси пары, Двойная задача |
| **Речь и словесное внимание** | Внимание в тексте, Анаграммы, Лишнее слово |
| **Мышление и логика** | Аналогии, 4-й лишний, Матрица |

## Уровни сложности

| # | Уровень | Что меняется |
|---|---------|-------------|
| 🟢 1 | Лёгкий | Больше времени (+50%), меньше объём, простые числа |
| 🟡 2 | Средний | Стандартный режим |
| 🟠 3 | Сложный | Меньше времени (−30%), сложнее задачи, больше объём |
| 🔴 4 | Экстрем | Минимум времени (−55%), максимальная сложность |

## Как добавить новую категорию

1. Создайте файл `js/categories/my_cat.js`
2. Добавьте в него:
```js
CATS.my_cat = {
  name: 'Название', desc: 'Описание',
  icon: '🎯', bg: '#eaf3de', fg: '#27500a',
  gen() {
    const lvl = getLvl(); // { id:1-4, timerMul, ... }
    // вернуть объект задания:
    return {
      q: 'Вопрос',
      vis: '<span>HTML визуал</span>',
      ans: 'ответ',
      opts: ['ответ','вар2','вар3','вар4']
    };
    // или { type:'my_type' } для кастомного рендерера
  }
};
```
3. Подключите в `index.html` перед `engine.js`
4. Добавьте id в нужный раздел в `registry.js`
